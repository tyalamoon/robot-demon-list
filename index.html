About RDL

A community leaderboard for robot challenges.

Robot Demon List collects player-submitted records. Submissions are stored for review and appear on the public leaderboard only after approval.

Geometry Dash is a game by RobTop Games. Robot Demon List is a community project and is not an official RobTop Games website.
